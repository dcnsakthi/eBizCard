🔑 Key Management

Manage one-time access keys for eBizCard

📋 Setup Instructions

  1. Go to your GitHub repository → Settings → Secrets and variables → Actions
  2. Create a secret named VALID_KEYS with comma-separated keys
  3. Create a secret named EBIZCARD_PAT_TOKEN with your GitHub Personal Access Token (with repo and workflow permissions)
  4. Use GitHub Actions workflows to manage keys:
    • manage-keys.yml: Add, remove, or list keys
    • generate-keys.yml: Deploy site with updated keys

Manual Key Management

To manually add or remove keys:

  1. Go to Settings → Secrets and variables → Actions → VALID_KEYS
  2. Edit the secret (comma-separated list of keys)
  3. Trigger the "Generate and Deploy with Keys" workflow to redeploy
